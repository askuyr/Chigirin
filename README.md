# Юридическое бюро Чигирина

Сайт юридической практики, подготовленный для размещения через GitHub Pages.

## Функции
- адаптивный сайт;
- разделы: Главная, Обо мне, Услуги, Практика, Контакты;
- форма обращения;
- генерация документа Word (.docx) с обращением в юридическое бюро Чигирина.

## Работа формы
Пользователь заполняет данные на сайте. После отправки браузер формирует Word-документ с маркировкой «Юридическое бюро Чигирина» и скачивает его на компьютер. Далее документ можно отправить на электронную почту бюро.

## Технологии
HTML5, CSS3, JavaScript, GitHub Pages.
