# Чигирин — сайт для GitHub Pages

Готовый адаптивный одностраничный сайт. Не требует установки библиотек, сборки, сервера или платных сервисов. Все стили и скрипты находятся в index.html. Можно открыть его двойным щелчком.

## Размещение на GitHub Pages

1. Создайте репозиторий на GitHub. Для бесплатного размещения в обычном личном аккаунте выберите Public (содержимое будет доступно всем).
2. Загрузите содержимое этой папки в корень репозитория: index.html должен находиться непосредственно в корне, а не во вложенной папке. Папку assets загрузите рядом с index.html, сохранив её название и содержимое.
3. Откройте Settings → Pages.
4. В Build and deployment выберите Source: Deploy from a branch, затем ветку main и папку / (root). Нажмите Save.
5. После успешного развёртывания GitHub покажет адрес опубликованного сайта в разделе Pages. Обычно это https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/.

Публикация на GitHub в рамках создания архива не выполнялась: ссылка на репозиторий и доступ к нему не предоставлены.

## Изменение

Откройте index.html в текстовом редакторе. Основные цвета задаются в блоке :root. Тексты находятся непосредственно в HTML. Все внутренние ссылки относительные или якорные, поэтому сайт работает и в подпапке GitHub Pages. Не добавляйте в файлы пароли и токены.

Инструкция сверена с документацией GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Проверены структура HTML, внутренние ссылки и синтаксис JavaScript. Полная визуальная проверка в браузере в среде создания не выполнена: браузер недоступен.
