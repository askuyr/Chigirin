# Кирилл Чигирин — сайт юриста

Одностраничный сайт юриста по гражданским спорам в Санкт-Петербурге.
Чистая статика для GitHub Pages: без сборки, фреймворков, сторонних библиотек
и внешних сервисов. Единственное действие на сайте — звонок или письмо.

## Структура


## Дизайн-система

Направление: «разделённая сцена». Портрет в зале Совета Федерации стоит
в правой половине первого экрана и уходит вместе с ним; без смены кадров
и без закрепления, только лёгкий параллакс внутри рамки. Слева идёт колонка
с текстом, набранная как юридический документ. Дальше страница раскрывается
на всю ширину, но держит ту же бумагу, синий и янтарь.

Палитра выбрана в UI UX Pro Max по профилю Legal Services: navy + trust gold.
Дизайн-настройки: смелость 5/10, анимация 7/10, плотность 7/10.

Токены лежат в `:root` в начале `assets/styles.css` и продублированы в
`assets/tokens.json`:

| Роль | Значение |
|---|---|
| Фон, бумага | `#f8fafc` |
| Поверхность, шаг тона | `#e9eef5` |
| Текст, тушь | `#0f172a` |
| Вторичный текст | `#475569` |
| Фирменный синий, поля | `#1e3a8a` |
| Синий, наведение | `#172554` |
| Действие, звонок | `#b45309` |
| Действие, наведение | `#8a3f07` |

- Заголовки: Cormorant Garamond 600, трекинг −0.02em, интерлиньяж 0.96–1.08.
- Текст: Inter 400/500/600, 17 px, интерлиньяж 1.6, мера 45–75 знаков.
- Шесть размеров: 14 / 17 / 22 / 28 / 40 / 92 px — мелкий, текст, лид,
  подзаголовок, заголовок секции, имя.
- Акценты: буквица в «О практике», серифные судебные реквизиты и подписи
  к фотографиям, янтарные номера шагов и «Результат», табличные цифры,
  неразрывные номера дел, висячая пунктуация.
- Сетка: внешние поля 28 px, одна вертикаль на всю страницу.
- Радиус: 0. Тени: нет. Градиенты: нет. Иконки: только стрелка «наверх».
- Акцент один: янтарная заливка кнопок звонка. Синий держит поля стоимости
  и контактов, ссылки и фирменный знак. Фотографии дают остальной цвет.
- Прокрутка: Lenis 1.3.27 локально, без CDN; при `prefers-reduced-motion`
  сглаживание, параллакс и появление секций отключаются.

Компоненты и состояния: кнопка (янтарная / бумажная на синем), текстовая
ссылка с подчёркиванием, пункт меню с `aria-current`, карточка услуги или дела
(без рамок и фона), синяя панель стоимости, поле контактов, кнопка «наверх».
Наведение и фокус — цвет, подчёркивание и подъём на 1 px; видимый фокус
`outline: 2px solid var(--blue)`, на синих полях — бумажный.

Шрифты локальные, OFL: [Cormorant Garamond](https://github.com/CatharsisFonts/Cormorant)
и [Inter](https://github.com/rsms/inter). Внешние CDN не используются: сайт
обязан работать без сторонних сервисов, поэтому в проекте лежат woff2
с кириллицей и латиницей. Макета в Figma нет: исходник — эта вёрстка и токены.

## Публикация

GitHub Pages, ветка `main`, папка `/ (root)`. Сборка не нужна: файлы
публикуются как есть. После деплоя проверьте, что `index.html` открывается
по адресу `https://askuyr.github.io/Chigirin/`.

Если домен изменится, замените адрес в `index.html` (canonical, OG, JSON-LD),
`privacy.html`, `consent.html`, `robots.txt` и `sitemap.xml`.

Все номера оформлены как `+7 921 974-65-17` в тексте и `tel:+79219746517`

## Как править тексты

Тексты лежат в разметке, каждый — в одном месте:

- `index.html`, секции помечены комментариями `<!-- ===== ... ===== -->`;
- FAQ продублирован в JSON-LD `FAQPage` в `<head>` — при правке ответа
  обновите оба места, иначе разметка разойдётся с контентом;
- услуги — блок `#services`: шесть статей в две колонки, внутри «ситуация,
  что делаю, на выходе»;
- кейсы — блок `#cases`: два примера из практики, имена сторон и персональные
  данные не раскрываются; исход каждого дела зависит от обстоятельств;
- контакты и режим работы — блок `#contact`.

Цвета, отступы и типографика заданы токенами в начале `assets/styles.css`.

## Доступность и производительность

- семантические заголовки, `alt` у изображений, видимый фокус, контраст AA;
- портрет в WebP с `srcset` и `width/height` — без сдвигов вёрстки;
- `prefers-reduced-motion` отключает анимации, смену кадра, движение фото
  и сглаживание Lenis;
- Lenis 1.3.27 — MIT, локальная копия в `assets/vendor/`, без CDN и сторонних
  запросов; при отключённом JS остаётся обычная прокрутка;
- появление секций не зависит от `app.js`: если скрипт не загрузился, через
  3 с класс `js-boot` снимается; есть и страховка через 5 с;
- шрифты локальные, `font-display: swap`, два файла предзагружаются;
- на мобильных закреплена шапка с кнопкой звонка; нижней панели нет;
- JSON-LD: `LegalService` и `FAQPage`, данные совпадают с содержимым страницы.

Замеры Lighthouse (mobile) выполняются на опубликованной версии сайта:
локальный сервер не отдаёт сжатие и HTTP/2 так же, как GitHub Pages.

## Проверка целостности

```
python tools/check_site.py            ошибки → код возврата 1
python tools/check_site.py --strict   предупреждения тоже считаются ошибками
```

Скрипт без внешних зависимостей. Проверяет локальные ссылки и якоря, наличие
файлов, `alt` у изображений, единый телефон и почту, `canonical`/`og:url`,
`sitemap.xml`, `robots.txt` и незаполненные реквизиты вида `[ ... ]`
в юридических документах.

## Генерация ассетов

```
python tools/gen_assets.py
```

Пересобирает `assets/og-chigirin.jpg`, `assets/apple-touch-icon.png`,
`assets/chigirin.vcf` и кадры портрета `assets/kirill-chigirin-{640,960,1280,1600}.webp`
из исходника `assets/kirill-chigirin.jpg` (3:4).

Нужны Python 3.8+ и Pillow (`pip install pillow`); шрифты Georgia и Arial
берутся из системной папки Windows, поэтому скрипт рассчитан на Windows.
Найденные фотографии уже подготовлены и лежат в `assets/`; их источники —
в `assets/credits.json`.

## Проверка перед публикацией

1. `python tools/check_site.py` — ошибок быть не должно.
2. `python -m http.server 8080` в папке проекта — пройти по всем ссылкам.
3. Проверить все телефонные ссылки на телефоне: номер должен открывать звонок.
4. Открыть страницы на ширинах 360 / 768 / 1024 / 1440.
5. Проверить `privacy.html` и `consent.html`: не осталось ли `[ ... ]`.
6. Прогнать Lighthouse на опубликованном адресе.

## История

Первая версия сайта была визиткой без формы обратной связи. В ходе доработки
пробовали вариант с формой заявки и приёмом сообщений через мессенджер, но
по решению владельца от него отказались: на сайте остаётся только звонок.
Блок «Практика» был удалён, затем возвращён двумя кейсами без сумм и имён.
В 2026 году сайт переведён на строгую бумажную айдентику с портретом
в Совете Федерации, архивным планом города и одной синей акцентной ролью.
Затем палитра уточнена по профилю Legal Services в UI UX Pro Max (navy +
amber), добавлены локальный Lenis и плотность 7: секции стали короче,
услуги — в две колонки, движение — заметнее.
