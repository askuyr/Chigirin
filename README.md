# Кирилл Чигирин — сайт юриста

Одностраничный сайт юриста по гражданским спорам в Санкт-Петербурге.
Чистая статика для GitHub Pages: без сборки, без фреймворков и сторонних
библиотек. Стили и скрипты вынесены в отдельные файлы, тексты — в разметку.

## Структура

```
index.html          — главная: hero, обо мне, услуги, порядок работы,
                      подход, стоимость, FAQ, контакты и форма
privacy.html        — политика конфиденциальности (152-ФЗ)
consent.html        — согласие на обработку персональных данных
404.html            — страница ошибки
robots.txt          — правила индексации
sitemap.xml         — карта сайта
assets/
  styles.css        — все стили (токены, компоненты, адаптивность)
  app.js            — меню, анимации появления, форма, cookie, CTA
  fonts.css         — @font-face для локальных шрифтов
  fonts/            — Inter и Cormorant Garamond (woff2, кириллица + латиница)
  kirill-chigirin-{480,640,800}.webp — портрет в кадрировании 4:5 для srcset
  kirill-chigirin.jpg               — исходник портрета (для пересборки кадров)
  og-chigirin.jpg                   — картинка для соцсетей 1200×630
  favicon.svg, apple-touch-icon.png
  chigirin.vcf                      — контакт для добавления в телефон
worker/
  src/index.js      — Cloudflare Worker: приём заявок → MAX + e-mail
  wrangler.toml     — конфигурация воркера
  README.md         — пошаговая инструкция по MAX и деплою
```

## Публикация

GitHub Pages, ветка `main`, папка `/ (root)`. Сборка не нужна: файлы
публикуются как есть. После деплоя проверьте, что `index.html` открывается
по адресу `https://askuyr.github.io/Chigirin/`.

Если домен изменится, замените адрес в `index.html` (canonical, OG, JSON-LD),
`privacy.html`, `consent.html`, `robots.txt` и `sitemap.xml`.

## Что нужно заменить перед запуском

| Что | Где |
|---|---|
| Ссылка на профиль в MAX | `assets/app.js`, константа `MAX_PROFILE_URL` |
| Адрес воркера для формы | `assets/app.js`, константа `FORM_ENDPOINT` |
| Реквизиты оператора (ФИО/ИП, ИНН, ОГРН, адрес, срок хранения) | `privacy.html`, `consent.html` — выделены подсветкой `[ ... ]` |
| Часы приёма | `index.html`, блок `#contact` (сейчас «Пн–Пт, 10:00–19:00») |
| Получатель заявок и токены | переменные окружения воркера, см. `worker/README.md` |

Токены и пароли в репозиторий не добавляются. В `assets/app.js` нет ни одного
секрета: только публичный адрес воркера.

## Форма заявки

Форма отправляет JSON на Cloudflare Worker (`POST /api/lead`). Воркер:

1. проверяет поля на сервере;
2. отбрасывает ботов по honeypot-полю `company`;
3. ограничивает частоту — один запрос с IP в 45 секунд;
4. отправляет заявку в MAX Bot API (`platform-api2.max.ru`);
5. дублирует заявку письмом (Resend).

Пока `FORM_ENDPOINT` пустой, форма не отправляет данные, а показывает телефон
и адрес почты — заявка не теряется молча. Полная инструкция по регистрации
бота, получению токена и деплою — в `worker/README.md`.

## Как править тексты

Тексты лежат в разметке, каждый — в одном месте. Ориентиры:

- `index.html`, комментарии `<!-- ===== Hero ===== -->` и далее по секциям;
- FAQ продублирован в JSON-LD `FAQPage` в `<head>` — при правке ответа
  обновите оба места, иначе разметка разойдётся с контентом;
- услуги и «стоимость» — блоки `#services` и `#pricing`;
- контакты и режим работы — блок `#contact`.

Цвета, отступы и типографика заданы токенами в начале `assets/styles.css`
(`:root`).

## Доступность и производительность

- семантические заголовки, `alt` у изображений, видимый фокус, контраст AA;
- формы с `label`, `aria-invalid` и текстом ошибок; статус отправки — `role="status"`;
- `prefers-reduced-motion` отключает анимации появления;
- шрифты локальные, `font-display: swap`, два файла предзагружаются;
- портрет в WebP с `srcset` и `width/height` — без сдвигов вёрстки.

Замеры Lighthouse (mobile) выполняются на опубликованной версии сайта:
локальный сервер не отдаёт сжатие и HTTP/2 так же, как GitHub Pages.

## Проверка перед публикацией

1. `python -m http.server 8080` в папке проекта — пройти по всем ссылкам.
2. Проверить форму: пустые поля, неверный телефон, отправка (когда воркер подключён).
3. Открыть страницы на ширинах 360 / 768 / 1024 / 1440.
4. Проверить `privacy.html` и `consent.html`: не осталось ли `[ ... ]`.
5. Прогнать Lighthouse на опубликованном адресе.

## История

Ранее в репозитории не было формы: связь шла только по телефону, почте и
ВКонтакте. Текущая версия добавляет форму, cookie-уведомление, страницу
политики по 152-ФЗ, мобильную панель действий и переработанные тексты.
Блок «Практика» удалён по решению владельца сайта.
