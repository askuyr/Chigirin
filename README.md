# Чигирин — сайт для GitHub Pages

Адаптивный одностраничный сайт юриста Кирилла Чигирина. Без сборки и зависимостей: стили и скрипты находятся в `index.html`, страница открывается двойным щелчком.

## Структура

```
index.html      — главная страница
privacy.html    — политика конфиденциальности
consent.html    — согласие на обработку персональных данных
404.html        — страница ошибки
assets/
  kirill-chigirin.webp — портрет для современных браузеров
  kirill-chigirin.jpg  — резервный вариант портрета
  og-chigirin.jpg      — картинка для соцсетей (1200×630)
  favicon.svg          — иконка сайта
  apple-touch-icon.png — иконка для iOS
  chigirin.vcf         — контакт для добавления в телефон
robots.txt      — правила индексации
sitemap.xml     — карта сайта
.gitignore      — служебные файлы, которые не публикуются
```

## Что задеплоить

В корень хостинга загружаются только:

- `index.html`, `privacy.html`, `consent.html`, `404.html`
- папку `assets/` целиком
- `robots.txt`, `sitemap.xml`

Не публикуйте: `README.md`, `.gitignore`, `_layout-test.html` (локальный тестовый файл, добавлен в `.gitignore`).

## Размещение на GitHub Pages

1. Создайте репозиторий на GitHub. Для бесплатного размещения в личном аккаунте выберите Public.
2. Загрузите файлы из списка выше в корень репозитория: `index.html` должен лежать непосредственно в корне, папку `assets` загрузите рядом, сохранив название.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите Source: **Deploy from a branch**, ветку `main` и папку `/ (root)`. Нажмите **Save**.
5. После развёртывания GitHub покажет адрес сайта — обычно `https://ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Альтернативы: Netlify или Vercel (достаточно перетащить папку проекта, сборка не нужна) либо обычный хостинг (загрузить те же файлы по FTP в корень сайта).

После публикации проверьте адреса в `sitemap.xml`, `robots.txt`, canonical-ссылках и Open Graph-метатегах: сейчас они указывают на `https://askuyr.github.io/Chigirin/`. Если репозиторий или логин другие, замените адрес в `index.html`, `privacy.html`, `consent.html`, `robots.txt` и `sitemap.xml`.

## Чего на сайте нет

Сайт не содержит форм отправки, сбора данных, аналитики и cookie-баннеров. Шрифты Inter и Cormorant Garamond загружаются с Google Fonts. Все тексты о порядке консультации носят редакционный характер.

## Изменение

Откройте `index.html` в текстовом редакторе:

- основные цвета задаются в блоке `:root`;
- тексты находятся непосредственно в HTML;
- внутренние ссылки относительные или якорные, поэтому сайт работает и в подпапке GitHub Pages;
- не добавляйте в файлы пароли и токены.

## Проверка

Проверены структура HTML, внутренние ссылки, синтаксис JavaScript, консоль браузера и адаптивность на ширинах 320, 375, 768 и 1024 px. Lighthouse: Accessibility — 100, Best Practices — 100, SEO — 100.

## Чек-лист публикации

1. Проверить `index.html` локально (двойной щелчок) и через локальный сервер.
2. Убедиться, что в консоли нет ошибок и все ресурсы отдают 200.
3. Проверить меню-бургер и якорные ссылки на телефоне.
4. Заменить домен в canonical/OG/sitemap/robots, если он отличается от `askuyr.github.io/Chigirin`.
5. Загрузить файлы из раздела «Что задеплоить».
6. Открыть опубликованный адрес, проверить 404-страницу и `sitemap.xml`.
