# Кирилл Чигирин — сайт юриста

Одностраничный сайт юриста по гражданским спорам в Санкт-Петербурге.
Чистая статика для GitHub Pages: без сборки, без фреймворков, без сторонних
библиотек и без внешних сервисов. Единственное действие на сайте — звонок
по телефону.

## Структура

```
index.html          — главная: hero, обо мне, услуги, порядок работы,
                      подход, кейсы, стоимость, FAQ, контакты
privacy.html        — политика конфиденциальности (152-ФЗ)
consent.html        — согласие на обработку персональных данных
404.html            — страница ошибки
robots.txt          — правила индексации
sitemap.xml         — карта сайта
.gitattributes      — единые окончания строк (LF)
assets/
  styles.css        — все стили (токены, @font-face, компоненты, адаптивность)
  app.js            — меню, анимации появления, кнопка «наверх», FAQ
  fonts/            — Inter и Cormorant Garamond (woff2, кириллица + латиница)
  kirill-chigirin-{480,640,800}.webp — портрет в кадрировании 4:5 для srcset
  kirill-chigirin.jpg               — исходник портрета (для пересборки кадров)
  og-chigirin.jpg                   — картинка для соцсетей 1200×630
  favicon.svg, apple-touch-icon.png
  chigirin.vcf                      — контакт для добавления в телефон
tools/
  check_site.py     — проверка целостности: ссылки, анкоры, alt, JSON-LD,
                      телефон и почта, sitemap, незаполненные реквизиты
  gen_assets.py     — пересборка OG-картинки, иконки, vCard и кадров портрета
```

## Публикация

GitHub Pages, ветка `main`, папка `/ (root)`. Сборка не нужна: файлы
публикуются как есть. После деплоя проверьте, что `index.html` открывается
по адресу `https://askuyr.github.io/Chigirin/`.

Если домен изменится, замените адрес в `index.html` (canonical, OG, JSON-LD),
`privacy.html`, `consent.html`, `robots.txt` и `sitemap.xml`.

## Конверсия

На сайте нет форм, счётчиков и мессенджеров — только телефон: `tel:+79219746517`.

- главная кнопка в hero — «Позвонить» с номером;
- телефон в шапке — ссылка `tel:` (на мобильных превращается в кнопку-иконку);
- на мобильных снизу липкая панель с одной кнопкой «Позвонить»;
- в контактах номер вынесен крупной ссылкой, ниже — e-mail, география, часы приёма.

Все номера оформлены как `+7 921 974-65-17` в тексте и `tel:+79219746517`
в ссылке. При смене номера меняйте оба варианта во всех файлах.

## Что нужно заменить перед запуском

| Что | Где |
|---|---|
| Реквизиты оператора (ФИО/ИП, ИНН, ОГРН, адрес, срок хранения) | `privacy.html`, `consent.html` — выделены подсветкой `[ ... ]` |
| Часы приёма | `index.html`, блок `#contact` (сейчас «Пн–Пт, 10:00–19:00») |
| Ссылки на ВКонтакте в JSON-LD `sameAs`, если профили изменятся | `index.html`, `<head>` |

## Как править тексты

Тексты лежат в разметке, каждый — в одном месте:

- `index.html`, секции помечены комментариями `<!-- ===== Hero ===== -->` и далее;
- FAQ продублирован в JSON-LD `FAQPage` в `<head>` — при правке ответа
  обновите оба места, иначе разметка разойдётся с контентом;
- услуги и стоимость — блоки `#services` и `#pricing`;
- кейсы — блок `#cases`: два примера из практики, имена сторон и персональные
  данные не раскрываются; исход каждого дела зависит от обстоятельств;
- контакты и режим работы — блок `#contact`.

Цвета, отступы и типографика заданы токенами в начале `assets/styles.css`
(`:root`).

## Доступность и производительность

- семантические заголовки, `alt` у изображений, видимый фокус, контраст AA;
- `prefers-reduced-motion` отключает анимации появления;
- шрифты локальные, `font-display: swap`, два файла предзагружаются;
- портрет в WebP с `srcset` и `width/height` — без сдвигов вёрстки;
- JSON-LD: `LegalService` и `FAQPage`, данные совпадают с содержимым страницы;
- появление секций не зависит от `app.js`: если скрипт не загрузился, через 3 с
  класс `js-boot` снимается и весь текст виден.

Замеры Lighthouse (mobile) выполняются на опубликованной версии сайта:
локальный сервер не отдаёт сжатие и HTTP/2 так же, как GitHub Pages.

## Проверка целостности

```
python tools/check_site.py            ошибки → код возврата 1
python tools/check_site.py --strict   предупреждения тоже считаются ошибками
```

Скрипт без внешних зависимостей. Проверяет локальные ссылки и якоря, наличие
файлов, `alt` у изображений, совпадение вопросов FAQ в JSON-LD и в разметке,
единый телефон и почту, `canonical`/`og:url`, `sitemap.xml`, `robots.txt` и
незаполненные реквизиты вида `[ ... ]` в юридических документах.

## Генерация ассетов

```
python tools/gen_assets.py
```

Пересобирает `assets/og-chigirin.jpg`, `assets/apple-touch-icon.png`,
`assets/chigirin.vcf` и кадры портрета `assets/kirill-chigirin-{480,640,800}.webp`
из исходника `assets/kirill-chigirin.jpg` (кадрирование 4:5, отступ сверху 18%
— как `object-position` в стилях).

Нужны Python 3.8+ и Pillow (`pip install pillow`); шрифты Georgia и Arial
берутся из системной папки Windows, поэтому скрипт рассчитан на Windows.
Размер JPEG немного зависит от версии Pillow — после пересборки сравните
результат с прежним файлом глазами.

## Проверка перед публикацией

1. `python tools/check_site.py` — ошибок быть не должно.
2. `python -m http.server 8080` в папке проекта — пройти по всем ссылкам.
3. Проверить все телефонные ссылки на телефоне: номер должен открывать звонок.
4. Открыть страницы на ширинах 360 / 768 / 1024 / 1440.
5. Проверить `privacy.html` и `consent.html`: не осталось ли `[ ... ]`.
6. Прогнать Lighthouse на опубликованном адресе.

## История

Первая версия сайта была визиткой без формы обратной связи. В ходе доработки
пробовали вариант с формой заявки и приёмом сообщений через мессенджер, но
по решению владельца от него отказались: на сайте остаётся только звонок.
Блок «Практика» удалён по решению владельца сайта.
