# Чигирин — сайт для GitHub Pages

Адаптивный одностраничный сайт юриста Кирилла Чигирина. Без сборки, зависимостей и платных сервисов: все стили и скрипты находятся в `index.html`, страница открывается двойным щелчком.

## Структура

```
index.html      — главная страница
privacy.html    — политика конфиденциальности
consent.html    — согласие на обработку персональных данных
404.html        — страница ошибки
assets/         — портрет kirill-chigirin.jpg
robots.txt      — правила индексации
sitemap.xml     — карта сайта
```

## Размещение на GitHub Pages

1. Создайте репозиторий на GitHub. Для бесплатного размещения в личном аккаунте выберите Public.
2. Загрузите содержимое этой папки в корень репозитория: `index.html` должен лежать непосредственно в корне, папку `assets` загрузите рядом, сохранив название.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите Source: **Deploy from a branch**, ветку `main` и папку `/ (root)`. Нажмите **Save**.
5. После развёртывания GitHub покажет адрес сайта — обычно `https://ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

После публикации проверьте адреса в `sitemap.xml`, `robots.txt`, canonical-ссылках и Open Graph-метатегах: сейчас они указывают на `https://askuyr.github.io/Chigirin/`. Если репозиторий или логин другие, замените адрес во всех файлах.

## Чего на сайте нет

Сайт не содержит форм отправки, сбора данных, аналитики и cookie-баннеров. Шрифты Inter и Cormorant Garamond загружаются с Google Fonts. Все тексты о порядке консультации носят редакционный характер.

## Изменение

Откройте `index.html` в текстовом редакторе:

- основные цвета задаются в блоке `:root`;
- тексты находятся непосредственно в HTML;
- внутренние ссылки относительные или якорные, поэтому сайт работает и в подпапке GitHub Pages;
- не добавляйте в файлы пароли и токены.
